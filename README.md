## Current research project

### Python-to-ESP8266 Edge-ML Reproducibility Study

A chronological forecasting case study with generated C++, complete 933-row host/device parity checks, and measured ESP8266 timing and whole-firmware resource use.

- [Code and reproducibility package](https://github.com/fouadiqbal/smart-meter-energy-load-forecasting)
- [LaTeX manuscript and compiled paper](https://github.com/fouadiqbal/smart-meter-energy-load-forecasting/tree/main/manuscript)
- [Interactive Kaggle notebook](https://www.kaggle.com/code/fouadiqbal/smart-meter-energy-load-forecasting)

The current evidence demonstrates numerical portability on one board and one normalized dataset. Calibrated electrical sensing and independent field validation are planned extensions.
